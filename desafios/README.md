# Desafios

Esta pasta reúne atividades práticas para exercitar os conteúdos das aulas. Cada desafio usa os arquivos e a interface já presentes no repositório; leia o enunciado e os comentários do código antes de fazer alterações.

| Desafio | Objetivo principal | Acesso |
| --- | --- | --- |
| [Correção de bugs — aulas 2 e 3](correcao-de-bugs-aulas-2-3/README.md) | Investigar comportamentos de operadores, condicionais, laços e funções. | `correcao-de-bugs-aulas-2-3/index.html` |
| [Arrays — aula 5](arrays-aula-5/README.md) | Aplicar operações de arrays em uma fila de atendimento. | `arrays-aula-5/index.html` |
| [Manipulação do DOM — aula 6](manipulacao-do-dom-aula-6/README.md) | Trabalhar com eventos, formulário e elementos criados pelo JavaScript. | `manipulacao-do-dom-aula-6/index.html` |

Abra os desafios com interface HTML no navegador, de preferência por um servidor local. Use o console do navegador quando a atividade pedir observação de saídas ou investigação de comportamento.

Os desafios fazem parte de um material progressivo. Comentários e blocos já existentes podem representar uma etapa de explicação; não os substitua sem primeiro entender o que estão demonstrando. Consulte também [Como estudar os exemplos](../docs/como-estudar-os-exemplos.md).
