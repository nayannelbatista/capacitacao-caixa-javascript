# Quizzes

Os quizzes são atividades interativas de revisão. Cada um apresenta questões, recebe uma resposta por vez e fornece retorno pela própria interface. Use-os para revisar conceitos após estudar as aulas e desafios relacionados.

| Quiz | Conteúdos avaliados | Como iniciar e utilizar |
| --- | --- | --- |
| [Manipulação do DOM](quiz-dom/README.md) | Seletores, eventos, classes, criação e remoção de elementos, formulários e closures. | Abra `quiz-dom/index.html`, escolha uma alternativa e avance pelas questões. |
| [Classes e POO](quiz-classes-poo/README.md) | POO, classes, objetos, atributos, métodos, `constructor`, `this`, `new` e validação. | Abra `quiz-classes-poo/index.html` e use o botão para começar. |
| [Estruturas de repetição e funções](quiz-javascript-repeticao-funcoes.html) | `for`, `while`, `do...while`, escopo, retorno e callbacks. | Abra o arquivo HTML, responda uma questão e use o botão de próxima questão. |
| [Fundamentos front-end, Node.js e npm](quiz_completo_fundamentos_frontend_node_npm.html) | Renderização, scripts, Node.js, npm, registry, dependências, `package.json`, `let` e `const`. | Abra o arquivo HTML, selecione uma alternativa e navegue pelas questões. |

## Orientações de utilização

- Abra o arquivo HTML indicado no navegador.
- Leia todo o enunciado e o código apresentado antes de responder.
- Use os controles da interface para avançar, voltar ou reiniciar quando disponíveis.
- Revise as explicações mostradas pela própria atividade depois de responder.

Os quizzes não substituem a leitura dos exemplos. Para compreender o caráter progressivo do material, consulte [Como estudar os exemplos](../docs/como-estudar-os-exemplos.md).
