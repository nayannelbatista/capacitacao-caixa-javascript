# Aula 5 — Arrays

## Objetivo e contexto

Esta aula introduz arrays como alternativa para lidar com uma coleção de valores relacionados. O arquivo preserva a passagem de variáveis de temperatura individuais para uma lista, antes de apresentar índices, percursos e operações que modificam a coleção.

## Conteúdos trabalhados

- criação de arrays e índices;
- propriedade `length`;
- leitura e sobrescrita de elementos;
- percursos com `for`, `for...of` e `forEach`;
- métodos `push`, `pop`, `unshift` e `shift`.

## Arquivo e observações

| Arquivo | Exemplo | O que observar |
| --- | --- | --- |
| `arrays.js` | Temperaturas e produtos | As variáveis `temperatura001` a `temperatura007` antecedem o array comentado e ajudam a motivar a coleção. Os exemplos comentados mostram diferentes percursos; o bloco ativo usa `produtos` para observar como os métodos adicionam e removem itens. |

Os trechos comentados são etapas de estudo. Ative apenas o conjunto necessário para a observação desejada, pois várias saídas foram preservadas para comparação.

## Como executar

O arquivo pode ser executado com Node.js a partir desta pasta:

```bash
node arrays.js
```

Os resultados das operações ativas aparecem no console.
