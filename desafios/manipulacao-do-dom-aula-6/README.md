# Desafio — Manipulação do DOM: inscrições

## Objetivo

Construir interações de uma página de inscrições para o evento fictício Conecta Tech. A atividade relaciona eventos do navegador, campos de formulário, alteração de classes e criação de elementos na página.

## Conteúdos trabalhados

- seleção de elementos com `querySelector`;
- eventos `click`, `input`, `change` e `submit`;
- `classList.toggle`;
- leitura de valores de formulário;
- `preventDefault`;
- arrays para armazenar inscrições;
- criação, configuração e inserção de elementos no DOM.

## Arquivos principais

- `index.html`: formulário, controles de tema, mensagens e área de participantes.
- `script.js`: referências aos elementos, desafios de eventos e criação dos cartões de inscrição.
- `style.css`: tema visual, modo escuro e estilos dos cartões criados pelo JavaScript.

## Como acessar e utilizar

Abra `index.html` no navegador, de preferência por um servidor local. A atividade pode ser explorada pelo botão de tema, pelos campos do formulário e pela confirmação de uma inscrição.

Os blocos “DESAFIO 1” a “DESAFIO 4” em `script.js` indicam os momentos de estudo: clique, digitação, mudança de seleção e envio do formulário.

## Orientações de estudo

- Observe qual elemento é selecionado antes de cada listener.
- Compare o evento recebido com a mudança esperada na interface.
- No envio do formulário, acompanhe a coleta dos valores, o armazenamento do nome, a criação do cartão e a atualização do contador.
- Leia o CSS do modo escuro junto com o uso de `classList` no JavaScript para entender a relação entre classe e apresentação.
