# Quiz — Classes e programação orientada a objetos

## Objetivo da atividade

Revisar fundamentos de programação orientada a objetos em JavaScript por meio de múltipla escolha, verdadeiro ou falso e interpretação de código.

## Conteúdos avaliados

- conceito de POO;
- diferença entre classe e objeto;
- atributos e métodos;
- `constructor`;
- `this`;
- instanciação com `new`;
- validação de dados em métodos.

## Arquivos principais

- `index.html`: telas de início, questões, resultado e revisão.
- `script.js`: banco de questões, controle de respostas e apresentação do retorno.
- `style.css`: aparência das telas, opções, progresso e resultado.

## Como iniciar e responder

Abra `index.html` no navegador e selecione **Começar o quiz**. Escolha uma resposta por questão e use **Próxima questão** para continuar. Ao final, a interface apresenta o resultado e a revisão correspondente; os controles permitem iniciar uma nova tentativa e filtrar a revisão pela própria interface.

## Orientações de utilização

Leia os blocos de código apresentados nas questões com atenção. O quiz foi estruturado para verificar entendimento de conceitos e comportamento de classes, não apenas memorização de palavras-chave.

## Relação com a trilha

O quiz revisa diretamente os objetos e as classes apresentados na [aula 6](../../aulas/aula-06/README.md). Também depende de fundamentos de funções e condições das aulas anteriores.
