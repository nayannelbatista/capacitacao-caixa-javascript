# Capacitação Caixa — Desenvolvimento Front-end

Materiais de apoio da capacitação em Desenvolvimento Front-end: exemplos construídos durante as aulas, desafios práticos e quizzes de revisão. O foco da trilha é avançar dos fundamentos de JavaScript para arrays, programação orientada a objetos, manipulação do DOM, consumo de API e TypeScript.

## Como ler este repositório

Os arquivos registram o processo de aprendizagem que ocorreu em aula. Por isso, um mesmo arquivo pode reunir uma abordagem inicial, tentativas intermediárias, variações do mesmo exemplo e uma solução mais elaborada. Trechos comentados, repetições de nomes e exemplos que produzem erros podem fazer parte da explicação.

Antes de executar qualquer exemplo, leia os comentários e consulte o guia [Como estudar os exemplos](docs/como-estudar-os-exemplos.md). Nem todo arquivo foi pensado para ser executado integralmente ou tratado como uma solução final.
