# Capacitação Caixa – Desenvolvimento Front-end

Repositório com materiais didáticos, exemplos práticos e atividades desenvolvidas durante a capacitação em Desenvolvimento Front-end.

## Conteúdos

### Aulas
Códigos-fonte e exemplos utilizados durante as aulas, organizados por encontro.

### Desafios
Atividades práticas para exercitar a lógica de programação, identificar e corrigir erros e aplicar os conceitos estudados.

### Quizzes
Questionários interativos para revisão e fixação dos conteúdos abordados.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Objetivo

Disponibilizar os materiais de apoio e atividades práticas da capacitação, facilitando o acompanhamento dos conteúdos e o desenvolvimento das habilidades de programação.
